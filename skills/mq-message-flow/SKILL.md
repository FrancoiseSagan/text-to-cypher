# MQ 消息流三阶段规范

## 1. 三阶段关系模型
消息流统一使用 `[:消息流]` 关系，由属性 `消息流类型` 区分三个阶段：
1. **发布阶段**：`(pub:方法)-[r1:消息流 {消息流类型: '发布至'}]->(ex:消息交换机)`，携带 `r1.路由键`
2. **路由阶段**：`(ex:消息交换机)-[r2:消息流 {消息流类型: '路由至'}]->(q:消息队列)`，携带 `r2.路由键`
3. **消费阶段**：`(q:消息队列)-[r3:消息流 {消息流类型: '消费自'}]->(sub:方法)`

## 2. 路由键对齐约束（关键！）
多个队列共用同一个默认交换机 `(default)`，**必须强制约束 `r1.路由键 = r2.路由键`**（或同时指定 `q.队列名称`），否则不同队列的消息流会在交换机处错误交叉！

## 3. 标准完整链路模板
```cypher
MATCH p=(pub:方法)-[r1:消息流 {消息流类型: '发布至'}]->(ex:消息交换机)-[r2:消息流 {消息流类型: '路由至'}]->(q:消息队列)-[r3:消息流 {消息流类型: '消费自'}]->(sub:方法)
WHERE r1.路由键 = r2.路由键
RETURN DISTINCT pub.moduleId AS 发布服务, pub.全限定名 AS 发布方法, r1.路由键 AS 路由键, ex.交换机名称 AS 交换机, q.队列名称 AS 队列名称, sub.moduleId AS 消费服务, sub.全限定名 AS 消费方法, p
```
